# Pappers-Hall 视觉重构 v0.20

> 方向：Apple 式克制的「研究台」。中性表面、单一蓝色行动色、SF Pro 界面字、阅读衬线只用于长文正文；胶囊主按钮、发丝分隔、克制动效。紫色只保留为 AI 标记。
>
> 基线：`2b82ecf`（tag `ph-baseline-v0.19.3`）。本文件记录这一轮的设计决策与控件归位，便于后续继续迭代。

## 1. 设计变量

| 类别 | 取值 |
|---|---|
| 字阶 | 11 / 12 / 13 / 15 / 17 / 20 / 26；界面正文 13 |
| 字体 | 界面 `SF Pro Text / SF Pro Display / PingFang SC`；阅读正文 `New York / Songti SC / Georgia` |
| 间距 | 4 / 8 / 12 / 16 / 20 / 24 / 32 / 48 |
| 圆角 | 6 / 8 / 12 / 16 / 20 / 999（按控件层级使用，不统一压平） |
| 行动色 | `#0071e3`，hover `#0077ed`，active `#0066cc`；白字约 4.6:1 |
| 表面 | 全部取 `--dsw-alias-*`，随宿主明暗主题；插件只定义强调色与中性交互色 |
| 交互底色 | hover 为正文色 5%，press 11%，选中为蓝色 8–10% |
| 阴影 | 三级：1px 贴地、卡片浮起、弹层深投影；不使用彩色发光 |
| 动效 | 150 / 220 / 320ms；统一 `cubic-bezier(0.28, 0, 0.22, 1)` |

单一蓝色承担：主按钮、选中、焦点环、进度、开关、链接。浅紫只用于 AI 作者标记（`.ph-n-doc__badge--ai`、AI 模式激活）。数据色只用于标签圆点、收藏夹圆点、批注色条、荧光笔，不承担正文层级。

## 2. 控件归位

| 层级 | 放在哪里 | 包含 |
|---|---|---|
| 全局 | 论文库顶栏右侧 | 导入（唯一主按钮）、更多（图片检索 / 重复文献 / 设置 / 刷新 / 快捷键） |
| 视图 | 论文库第二行工具栏 | 左栏开关、排序、表格/卡片、结果数、右栏开关 |
| 浏览 | 左栏 | 浏览（全部/最近/有批注/回收站）、收藏夹、我的文件夹、标签、笔记 |
| 单篇 | 详情栏标题区 + 上下文菜单 | 打开阅读器、引用到对话；关闭/折叠在栏头 |
| 多选 | 底部浮动批量条 | 引用到对话（主）、收藏；文件夹、标签、集合、阅读状态、复制引用、更新指标、删除 |
| 阅读 | 阅读器两行工具条 | 第一行：返回、标题、引用、AI、笔记；第二行：页码、缩放、原文/对照/译文、搜索、右栏 |
| 写作 | 笔记文档头 + 编辑器工具栏 | 标题、文件夹、关联论文、字数、保存态、更多；AI 美化、视图、历史在工具栏 |
| 引用 | 抽屉 / 草稿 dock | 搜索、多选、引用所选；草稿卡片的加入/撤销/移除 |

原则：一个视图只保留一个主按钮；低频操作进「更多」；选中操作只出现在批量条；单篇操作只出现在详情区和右键菜单。

## 3. 各界面

### 论文库
- 顶栏改为三列网格：品牌 / 居中搜索（带 ⌘K 提示）/ 右侧行动；半透明毛玻璃。
- 工具栏去掉导入与导出类动作，只保留视图和面板控制；排序收成带图标的安静下拉。
- 左栏加「浏览」分区头；所有分区统一 10.5px 大写标签、30px 行高、圆角 7px、蓝色淡底选中。
- 表格 44px 行高；标题 13px/600，原题 11px；选中用 8% 蓝底 + 2px 左条；表头中性化并吸顶。
- 详情栏新增标题区：题名、原题、作者/年份/期刊、打开与引用两个动作；信息页改为纯元数据表，避免与标题区重复。
- 批量条改为底部浮动胶囊：计数、主行动、次要动作组；≤1320px 次要按钮转图标，窄屏可横向滚动。

### 笔记
- 顶栏 56px；文件夹 220px、列表 304px、论文面板 320px。
- 列表行是轻卡片：13px 标题、两行摘要、时间/文件夹/论文数；选中带 2px 蓝条。
- 编辑器是居中页面：文档头 26px 衬线标题 + 元信息 + 保存态；正文 760px 限宽、15.5px/1.85 衬线；卡片视图 860px。
- 阅读列（`.ph-n-md`、`.ph-n-doc__body`）统一 15px/1.82 衬线；章节卡 12px 圆角、发丝边。

### 阅读器
- 工具栏 58/44px 两行，滚动后收缩为 46px 单行；搜索打开时工具行强制保留。
- 缩略图栏 96px；画布中性底 + 纸张投影；当前页缩略图 2px 蓝环。
- 右栏 356px，四个页签改为胶囊分段；目录/批注/双语/AI 统一 46px 栏头。
- 选区工具条、批注卡、翻译浮层统一 12px 圆角与深投影。

### 外围
- 抽屉行、草稿卡片、设置面板、图片检索、命令面板、引用弹窗共用同一套按钮层级、圆角、焦点环和 hover 底色。
- 设置面板 18px 圆角、56px 栏头、分区卡片。
- 状态栏压到 30px，弱化为信息带，不与主行动竞争。

## 4. 动效

| 场景 | 时长 / 曲线 |
|---|---|
| 行/卡片首次载入 | 220ms，24ms 级联，最多 8 项 |
| 页签/分段气泡 | 280ms ease-out，内层 300ms 先收后放 |
| 面板开合 | 320ms ease-out |
| 详情页切换 | 220ms 上移 4px 淡入 |
| 批量条出现 | 240ms spring |
| 菜单出现 | 160ms ease-out |
| 阅读页切换 | 240ms 淡入上移 3px |
| 保存态 | 呼吸点常驻，不闪烁 |

`prefers-reduced-motion: reduce` 下关闭所有位移、缩放、级联和气泡动画，保留即时状态变化。

## 5. 断点

| 宽度 | 行为 |
|---|---|
| ≥1320 | 批量条显示文字标签；三栏完整 |
| 1320 | 批量条次要按钮转图标；副标题隐藏 |
| 1180 | 表格隐藏作者列；右栏 304px |
| 1420 / 1250 | 笔记论文面板 / 文件夹栏默认收起（首次进入） |
| 1120 | 笔记论文面板变覆盖层 |
| 1100 | 论文库左栏变覆盖层（与 JS 的 narrow 阈值一致） |
| 1000 | 笔记文件夹栏变覆盖层 |
| 980 | 顶栏两行（搜索独占一行）；工具栏可换行；批量条横向滚动 |
| 820 | 阅读器右栏覆盖；笔记论文面板覆盖 |
| 760 | 右栏覆盖；表格只留标题/年份/已读；批量条更紧凑 |
| 640 | 笔记列表覆盖；编辑器全宽 |

## 7. 验收与限制

- `node client/build.mjs` 通过（esbuild，无新增依赖）。
- 本轮环境无法打开 DSH 做真实截图；观感需在 DSH 中重载插件并刷新页面确认。
- 未改 `host/**`、数据请求、自动保存、AI 美化/方向浮层；未新增 React 之外的依赖。
- 保留全部 `ph-*` 类名、`aria-*`、`title`、`data-*` 钩子。
- 深色模式仍由宿主 token 驱动；插件只覆盖强调色与中性交互色。
