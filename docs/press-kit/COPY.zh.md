## 项目介绍长帖

读论文时，真正费力的往往不只是理解原文，还有把零散的图表、摘录、笔记和问题重新接起来。

Pappers-Hall 想把这些事放到一张连贯的科研工作台上。

它是一个原生融入 DeepSeek Harness 的社区插件：你可以导入 PDF 与常见书目格式，用文件夹、标签和阅读状态整理文献；在原始页面上选词、批注、定位图表；把关联论文放在笔记旁边，边读边写下自己的理解。

需要整理表达时，独立笔记 Agent 可以把内容排成重点卡片、比较表、图表、时间线或思维导图。原始 Markdown 和排版结果分别保存，笔记也有历史版本。

继续追问时，把论文、图表、批注或笔记引用到 DSH 对话，让问题带着具体材料出发，也方便回到原文核对。资料保存在本地，AI 功能使用自己在 DSH 中配置的模型服务。

现在项目仍在开发，GitHub 提供的是预发布版本。欢迎先从一篇论文开始试用，把不顺手的地方、真实的阅读需求和复现场景告诉我。
